# 游戏自动化 (game-autotask)

一个 Python 写的小调度台：早上按时把常用手游的日常挨个跑完，出错了自己重启，跑完发一封邮件告诉我结果，
最后弹一个倒计时关机窗口。人还在上课，任务已经在跑了。

## 流程

```
明日方舟 (MAA) → 崩坏：星穹铁道 (三月七助手) → 原神 (BetterGI) → 崩坏三 (MFW)
        ↓ 全程写日志
   邮件汇报 + 按日期归档日志 + 倒计时关机（可取消）
```

## 特性

- **进程编排**：等待上一个程序退出、确认没有重启，再拉下一个；每步都有超时保护。
- **自我修复**：连续运行超过一小时未退出就重启软件；关键奖励没拿到会重跑对应步骤。
- **静默与前奏**：`begin.bat` 先停掉音频服务避免干扰，`end.bat` 跑完恢复。
- **结果可查**：`create_flag.bat` 打完成标记，日志按天归档，最后邮件发到指定邮箱。

## 用之前要改的

- 程序路径（`ASSISTANT_PATH` / `MAA_PATH` / `BETTERGI_SCRIPT` / `BH3_SCRIPT`）按你的目录改。
- **邮箱授权码**：代码里读的是环境变量 `SMTP_PASSWORD`，请不要把授权码写进仓库。
  发件/收件邮箱也请改成你自己的。

## 打包

```bat
pyinstaller --onefile AutoTask.py
```

放进 Windows 任务计划程序，登录时触发即可。
